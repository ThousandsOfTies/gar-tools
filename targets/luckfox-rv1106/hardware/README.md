# Luckfox RV1106 Hardware Template

Default hardware definition CSV files for the Luckfox RV1106 target.

`GaplessAgentRuntime` can copy these files into the local project `hardware/`
directory with:

```bash
gar hw init
```

The local `hardware/` directory is a project-specific override. This directory
in `gar-tools` remains the template source of truth.
